# Thought #80

[ChatGPT: API Requires Account Signup | 2023-10-20] Using the OpenAI GPT-3.5 API
requires creating an account; it is not possible to access the API anonymously.
The account is necessary to manage API keys, track usage quotas, and adhere to
OpenAI's usage policies.
