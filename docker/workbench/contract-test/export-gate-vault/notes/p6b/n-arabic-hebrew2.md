# RTL

العربية: مَرْحَبًا بِالْعَالَمِ. اللُّغَةُ الْعَرَبِيَّةُ جَمِيلَةٌ، وَالْكِتَابَةُ مِنَ الْيَمِينِ إِلَى الْيَسَارِ. لا إله. الأرقام ١٢٣٤٥٦٧٨٩٠ و 2026.

فارسی: زبان فارسی زیباست.

עברית: שָׁלוֹם עוֹלָם. בְּרֵאשִׁית בָּרָא אֱלֹהִים אֵת הַשָּׁמַיִם וְאֵת הָאָרֶץ. מספרים 2026.

Mixed direction: the word مرحبا means hello, and שלום means peace (both 2026).
