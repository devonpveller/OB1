# 中文与日本語

研究工作台的导出验证门检查每一个导出的文件。「引号」『双引号』、顿号，逗号。句号！感叹号？问号；分号：冒号（括号）《书名号》——破折号……省略号。

日本語の文章です。「かぎ括弧」、読点。句点！「引用」（括弧）『二重』・中黒、カタカナ、ひらがな、漢字。長い文章が次の行へ折り返すことを確認するための文です。

한국어 문장입니다. 「인용」, 쉼표. 마침표! 물음표? 괄호(예) 그리고 긴 문장이 다음 줄로 넘어가는지 확인합니다.

Mixed: the term 研究 (research), 「study」, 'survey', and 《review》, 1。2、3，4！
